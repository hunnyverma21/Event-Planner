# Evently - Event Planner

A responsive, browser-based event planning dashboard built with HTML, CSS and JavaScript.

## Features
- Create, edit and delete events
- Event category, date, time and venue
- Guest count and estimated budget
- Tasks and notes for each event
- Dashboard statistics for total events, upcoming events and combined budget
- Search and category filtering
- Saves event data in browser `localStorage`
- Responsive layout for desktop and mobile

## Run locally
1. Extract the ZIP file.
2. Open `index.html` in Chrome, Edge, Firefox or another modern browser.
3. Click **New Event** to add your first event.

No installation or internet connection is required.

## Project structure
- `index.html` - page structure
- `style.css` - layout and styling
- `script.js` - event management and browser storage

## Note
Events are stored in the browser on the device where they are created. Clearing browser site data may remove them. This project does not include cloud sync or multi-user accounts.
